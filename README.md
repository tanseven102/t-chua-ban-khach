# T-CHÚA — bản cài cho khách

Tool dựng video kênh Chúa (tiếng Anh) tự động: viết bài → đọc giọng → vẽ ảnh → dựng video → SEO.

## Tải về (luôn là bản mới nhất)

**https://github.com/tanseven102/t-chua-ban-khach/releases/latest/download/T-CHUA-ban-khach.zip**

## Cài đặt (Windows 10/11)

1. Giải nén file zip ra một thư mục (vd `Desktop\T-CHUA-cai`).
2. Bấm đúp **CAI DAT T-CHUA.bat**. Lần đầu mất 10–20 phút. Máy chưa có Ubuntu (WSL) thì bộ cài tự cài, xong khởi động lại máy rồi bấm lại.
3. Ngoài Desktop có 2 lối tắt:
   - **T-CHUA - Dang nhap ChatGPT**: bấm 1 lần, đăng nhập ChatGPT của bạn (nên dùng gói Plus) — tool viết bài bằng ChatGPT web, không tốn tiền API.
   - **T-CHUA**: mở tool. Lần đầu màn hình hiện **MÃ MÁY** → bấm Chép, gửi người bán. Người bán gửi lại **KEY** → dán vào, bấm Kích hoạt. Mỗi KEY chỉ dùng trên 1 máy, có hạn.
4. Trong tool bấm **🔑 Key**, dán khoá API **của bạn**:

| Ô | Bắt buộc | Lấy ở đâu |
|---|---|---|
| OpenAI API key | ✅ | https://platform.openai.com/api-keys |
| ai33 API key (đọc giọng) | ✅ | https://ai33.pro |
| Vẽ ảnh: T-TẠO ẢNH (card NVIDIA, cùng máy) | — | mở T-TẠO ẢNH lên là tool tự tìm, không cần khoá |
| Vẽ ảnh: Khoá API T-AI (Google Flow) | dùng khi không có card | mở T-AI → mục API |
| Pexels / Pixabay / Anthropic | tuỳ chọn | pexels.com/api · pixabay.com/api/docs |

Thiếu khoá bắt buộc thì tool không chạy. Khoá chỉ lưu trên máy bạn.

5. Video dựng xong nằm ở `Videos\T-CHUA`.

## Cập nhật bản mới
Tải lại link trên, giải nén, bấm lại **CAI DAT T-CHUA.bat**. Key, dữ liệu và mã kích hoạt giữ nguyên.
